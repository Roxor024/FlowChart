# Azure documentation per step

Checked Microsoft Learn pages. The Functions, Logic Apps and Service Bus links come from v0.4; the others were checked on 2026-11-06. In `guide-extras.json`, a link from this list may be marked `"verified": true`. Any other link is `"verified": false` unless you opened it in this session. Every build task needs at least one link; pick the closest page below.

## Compute and workflows
- Python Azure Functions: https://learn.microsoft.com/en-us/azure/azure-functions/functions-reference-python
- Create Standard Logic Apps: https://learn.microsoft.com/en-us/azure/logic-apps/create-single-tenant-workflows-azure-portal
